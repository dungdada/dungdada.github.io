  • timm
  • 320px

  • threshold 보정

  1. SimpleCNN → ResNet18/34/50 → EfficientNet-B0. 5,200장 규모에서는 큰 모델일수록 과적합돼, 표현력과 크기의 균형점을 찾는 문제였습니다
  2. 입력 해상도를 128 → 224 → 320px로 올려 미세 음영을 보존. 384는 학습 부담 대비 이득이 없었습니다
  3. 클래스 불균형(정상 1,341 : 폐렴 3,875)에 class weight를 적용하고, best model 저장 기준을 accuracy가 아닌 F1로 변경
  4. threshold 0.48 + seed42·seed7 확률 앙상블(0.55 : 0.45). threshold를 0.475, 0.45까지 더 낮추자 위양성이 늘어 점수가 떨어졌습니다 — 앙상블도 많이 섞는 것보다 보완되는 비율을 찾는 게 중요했습니다
