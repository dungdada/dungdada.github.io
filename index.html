01 이어봄 — 대화형 건강비서 '봄이'

2026.08 –

가족의 건강기록을 로컬 우선으로 보관하고 만성질환 위험을 관리하는 웹 서비스입니다. 팀 3인 중 저는 AI 에이전트 전 영역을 맡았습니다.

문제
건강 질문은 틀리면 안 되는 질문입니다. 일반 챗봇처럼 "그럴듯한" 답을 내면 임신 중 복약이나 혈당 수치처럼 위험한 영역에서 바로 신뢰가 무너집니다. 동시에 사용자의 질문은 대개 짧고 모호해서, 그대로 LLM에 넘기면 엉뚱한 답이 나옵니다.
선택 — 입력 파이프라인 3단
  • 정규식 하드룰 — 욕설·탈옥 시도를 LLM 호출 전에 차단
  • 룰 기반 패스트패스 — "안녕", "혈압 120/80 기록해줘"처럼 의도가 확정적인 발화는 LLM 분류를 건너뛰고 0.001초에 응답
  • LLM 맥락 추론 + 쿼리 빌딩 — 남은 모호한 질문만 소형 모델로 의도를 넓혀 툴 라우팅에 넘김
판정 정확도와 지연을 함께 재는 벤치마크 스크립트를 만들어, 케이스별 라우팅 결과와 응답 시간을 회귀 없이 관리했습니다.
선택 — 툴 콜링 6종
식약처 의약품·DUR 병용금기 · 식품의약품안전처 식품영양성분 · 기상청 단기예보 + 에어코리아 대기질 · 국립중앙의료원 전국 병원·약국·응급실 · 질병관리청 국가건강정보포털 · 사용자 개인 건강기록 조회
  • "이 약이랑 영양제 같이 먹어도 돼?" → DUR 조회 후 말풍선 일체형 카드로 응답
  • "오늘 운동해도 될까?" → 날씨·대기질을 동시에 조회해 실내/실외 운동을 근거와 함께 추천
  • 여러 툴을 asyncio.gather로 병렬 호출하고, 한 API가 죽어도 나머지 결과로 답하는 부분 성공 처리
선택 — 근거 그라운딩
응답 전체가 아니라 주장 문장 단위로 근거를 검사합니다. 연결된 공식 정보에서 근거를 찾지 못하면 답을 지어내지 않고 "확인하지 못했다"고 말하고 멈춥니다. 임신·복약처럼 개인화가 위험한 질문에는 답 대신 확인 질문을 먼저 던지도록 분기를 결정론적으로 고정했습니다.

02 스트레스 지수 예측

최종 2위

건강·생활습관 테이블로 스트레스 지수를 예측하는 회귀 문제. 팀 3인.

문제
데이터에 동일 피처 중복 행이 많았습니다. 무작정 K-Fold를 돌리면 같은 사람이 train과 valid에 나뉘어 들어가 로컬 점수만 좋아지고 리더보드는 떨어집니다.
선택
  • 중복 행을 하나의 그룹으로 묶는 StratifiedGroupKFold, 결측 대치·인코딩은 각 fold의 학습 부분에서만 fit
  • Test에는 어떤 통계도 fit하지 않는 규칙을 코드로 강제해 누수 경로를 차단
  • 동일 피처 쌍을 매칭해 값을 전이하고, 매칭 실패 시 모델 예측으로 되돌리는 pair + fallback 하이브리드 설계
  • MAE 목적에 맞춰 Quantile ExtraTrees 다중 조합을 앙상블, CatBoost·XGBoost·LightGBM·TabPFN과 비교
결과
최종 점수 0.1246, 리더보드 최종 2위. 단순 중앙값 기준 MAE 약 0.249 대비 큰 폭 개선.

약 5,200장 규모 의료영상 이진 분류. 개인 프로젝트로 전 과정 수행.

문제
SimpleCNN 베이스라인은 흉부 X-ray의 미세한 음영 변화를 잡지 못했고, 정상 1,341장 : 폐렴 3,875장의 클래스 불균형과 5,200장이라는 작은 데이터 규모가 겹쳐 큰 모델일수록 오히려 과적합됐습니다.
선택
  • ResNet18/34/50과 비교해 EfficientNet-B0 채택 — 5,200장 규모에서 표현력과 모델 크기의 균형이 가장 좋았음
  • 입력 해상도 128 → 224 → 320px. 384는 학습 부담 대비 이득이 없었음
  • CrossEntropyLoss에 class weight를 넣고, best model 저장 기준을 accuracy가 아닌 F1로 변경
  • threshold 0.48 + seed42·seed7 확률 앙상블 0.55 : 0.45
결과와 실패
  • 최종 0.95673 · 19위. Validation Accuracy 0.9980 / F1 0.9987
  • threshold를 0.475, 0.45까지 더 낮추자 false positive가 늘어 점수가 떨어졌습니다. 앙상블도 seed7 비중을 높일수록 나빠졌고, 많이 섞는 것보다 보완되는 비율을 찾는 게 중요했습니다.
  • Grad-CAM으로 오답 이미지를 열어 모델이 폐 영역이 아닌 배경·마커를 보고 있는지 확인

05 난임 환자 임신 성공 여부 예측

최종 13위

난임 시술 임상 데이터 기반 이진 분류. 팀 3인.

문제와 선택
  • 시술유형 · 특정시술유형 · 통합시술유형처럼 의미가 겹치는 임상 변수를 정리해 중복 신호를 제거
  • 결측을 채우는 대신 결측 자체를 정보로 다루는 부스팅 계열(CatBoost·XGBoost·LightGBM)에 그대로 넘기는 전략을 비교 검증
  • CatBoost 기반 최종 모델과 Optuna 하이퍼파라미터 탐색을 담당하고, 팀 실험 결과를 모아 제출 조합을 선정
결과
최종 점수 0.74101 · 13위. 첫 팀 단위 ML 프로젝트로, 실험 기록을 공유하고 최종 모델을 합의하는 과정을 익혔습니다.
